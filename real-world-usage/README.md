## Delivery standard

Every project should include architecture notes, a threat model, automated tests, deployment instructions, observability, rollback guidance, and an operations runbook. Build the required scope before attempting optional extensions.

Company names and business scenarios are fictional. The technical constraints are intended to resemble real production work.
