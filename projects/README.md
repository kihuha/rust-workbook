# Rust projects

These projects combine several Rust skills in one practical build. Unlike the chapter challenges, they are organized by project scope rather than by language topic.

## Difficulty levels

- [Easy](easy/README.md) — small command-line programs with focused state and file handling.
- [Medium](medium/README.md) — multi-module applications with persistence, concurrency, or external I/O.
- [Hard](hard/README.md) — larger systems with protocols, scheduling, recovery, or substantial architecture.

## How to use the briefs

1. Create a separate Cargo package for each project.
2. Build the smallest end-to-end flow first.
3. Keep domain logic separate from terminal, file, network, or database I/O.
4. Add tests for the examples and failure cases in the brief.
5. Finish the required behavior before attempting stretch goals.

Output wording may differ from the examples unless a format is explicitly required. The data and behavior should still match.
